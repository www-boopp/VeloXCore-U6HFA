VeloXCore — نسخة قابلة للتثبيت

كل الملفات موجودة في مستوى واحد لتتمكن من رفعها مباشرة إلى جذر مستودع GitHub.

الرفع من موقع GitHub:
1. أنشئ مستودعًا جديدًا.
2. افتح المستودع واختر Add file ثم Upload files.
3. فك ضغط هذه الحزمة، وحدد الملفات الموجودة داخلها كلها (لا ترفع ملف ZIP نفسه).
4. اترك الملفات في الجذر، ثم اضغط Commit changes.
5. افتح Settings ثم Pages.
6. اختر Deploy from a branch، ثم الفرع main والمجلد /(root)، واضغط Save.
7. بعد اكتمال النشر، افتح رابط Pages عبر HTTPS.

لا تغيّر أسماء الملفات أو أماكنها. يستخدم manifest الأيقونات القياسية بأحجام
180 و192 و512. أزيلت المساحة البيضاء الخارجية فقط من صورة الشعار، وأصبحت
الخلفية حول الأيقونة شفافة؛ لم يُعد رسم الشعار أو تغيير ألوانه.
يكفي فتح index.html محليًا للمعاينة؛ التثبيت يحتاج موقع HTTPS.
